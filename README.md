# Our Roadmap — Mind X Associates

Public roadmap of the Mind X Associates psychotherapy collective, live at
https://projects.mindx.us/roadmap/

This page is a full-page iframe embed of the Public Roadmap web app
(Apps Script, "Public Roadmap" project). The app reads the practice's
Roadmap sheet and shows only the items marked public (Public? = Yes with
a public summary), in English and Chinese. Edit the roadmap in the
Roadmap Editor — this embed never needs to change unless the app's
/exec URL changes.
